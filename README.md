# Git and GitHub Learning Journey

## Overview

This repository was created as part of my internship training
to understand Git and GitHub version control workflows.

## Topics Covered

- Git configuration
- GitHub repository creation
- Repository cloning
- Git staging
- Git commits
- Branch creation
- Branch switching
- Pull requests
- Pull request review
- Pull request merging
- README documentation

## Git Workflow

The basic workflow followed in this repository is:

1. Create or modify files
2. Check repository status
3. Stage changes
4. Commit changes
5. Push changes to GitHub
6. Create a feature branch
7. Create a pull request
8. Review changes
9. Merge the pull request

## Learning Outcome

Through this practical exercise, I learned how Git tracks changes
and how GitHub can be used to manage repositories and collaborate
using branches and pull requests.
